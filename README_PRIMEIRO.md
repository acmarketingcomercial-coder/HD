# Internet JVX — Pacote para Claude Code

1. Extraia o ZIP numa pasta local.
2. Abra essa pasta no Claude Code.
3. Copie todo o conteúdo de `PROMPT_CLAUDE_CODE.md` para o Claude Code ou peça: **“Execute o briefing de `PROMPT_CLAUDE_CODE.md`, respeitando a etapa de prévia antes do render completo.”**
4. Mantenha a pasta `assets/` intacta: inclui **narrador já gravado** e **logo JVX PNG original**. Não precisam ser recriados.
5. O áudio tem 60,9175 segundos. A tabela de cenas do prompt é **provisória**; a locução real governa sincronização e duração.
6. Nenhum outro asset (aparelhos, fotografia, trilha, efeitos ou fonte Poppins) está presente neste pacote. O prompt instrui como obter ou criar cada um, com o devido controle de qualidade e licença.

Não há vídeo renderizado neste pacote. Ele contém briefing técnico, locução, logotipo e notas de sincronização para orientar a produção futura no Claude Code.
