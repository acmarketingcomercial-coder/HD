# Direção de Motion + Sound Design

## Motion
- Conexões físicas entre cenas: clique atravessa tela, foto vira planta, linha de projeto vira traçado entre perguntas.
- Motion editorial dá ênfase ao conceito; não usar palavras gigantes apenas para preencher tempo.
- Acting dos avatares: antecipação, reação, blink parcimonioso, eye-line, microgestos e peso.
- Movimentos devem nascer de motivação narrativa; alternar ritmo, não aplicar easing idêntico em tudo.
- Separar câmera virtual, personagens, props e UI em camadas com IDs para QA.

## Som como narrativa
| Momento | Intenção | Direção sonora |
|---|---|---|
| Gancho | Ruptura/curiosidade | Clique que falha + pausa curta |
| Publicação visual | Aparente conclusão | Toque delicado e música suave |
| Dúvida do comprador | Incerteza | Ambiência reduzida, papel/planta |
| Conversa comercial | Investigação | Folhear de anotações, cliques de seleção |
| Descoberta | Coerência | Elementos sonoros que se encaixam |
| Reflexão final | Espaço para pensar | Música recua, não sobrepor CTA |

- Quem dirige o timing é a voz gravada, nunca estimativa arbitrária.
- SFX originais/licenciados; se geração externa indisponível, documentar prompts e pendências, sem som inventado.
- Mixagem inteligível em celular, sem saturação, sustos ou sons concorrendo com voz.
- Evitar beep genérico e graves excessivos; nem todo movimento produz som.
- Produzir stems de VO/SFX/Música quando disponíveis para revisão.
