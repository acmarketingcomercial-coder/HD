# QA de Motion Design — Franciele Fotografias

## Pré-render
- [ ] Arquivos OGG/logo/capa aberta/mockup 3D estão presentes, sem substituições.
- [ ] SHA-256 de cada asset corresponde ao MANIFEST.json.
- [ ] OGG real: duração 35,6465s, voz íntegra, sem gravação artificial.
- [ ] Locução foi ouvida/transcrita; qualquer divergência com roteiro bloqueado documentada.
- [ ] A peça original está dobrada: lado direito frontal com título, lado esquerdo contracapa.
- [ ] Mockup 3D é render raster aprovado, não mesh 3D.
- [ ] Marcas impressas na arte são preservadas; sem textos novos.
- [ ] Foto de ensaio real autorizada identificada para final completo.

## Prévia 0–12 segundos
- [ ] Abertura comunica objeto/carnê em movimento até 2 segundos.
- [ ] Há continuidade real, sensação de volume, luz/sombra e dobra física.
- [ ] Sem números, moeda, CTA ou legenda sobreposta.
- [ ] O som de papel está sincronizado com a ação e não disputa com a voz.
- [ ] Frames 0, 2, 5, 7, 10, 12 segundos inspecionados.
- [ ] MP4 com áudio entregue para aprovação antes do vídeo completo.

## Completo
- [ ] Nenhum rosto sintético ou alteração de fisionomia.
- [ ] Quatro cartões tratados como ilustração, não parcelas prometidas.
- [ ] Há transformação cartão -> moldura -> fotografia real autorizada.
- [ ] Um único disparo de câmera no ápice da revelação.
- [ ] Narração não foi acelerada nem cortada; sem clipping ou ruído excessivo.
- [ ] Música com uso comercial permitido, dinâmica não encobre voz.
- [ ] Sem telas de slides independentes; movimentos com propósito.
- [ ] H.264, yuv420p, 1080x1920, 30fps, AAC 48k, faststart, MP4.
- [ ] ffprobe confere duração e trilhas; true peak <= -1 dBTP quando aplicável.
- [ ] Frames críticos inspecionados; nenhum corte seco, tela preta ou erros de máscara.
- [ ] Arte da marca/capa/logo não foi redesenhada.
- [ ] Entregues projeto-fonte, vídeo, mapas de cues, licenças e relatório de QA.
- [ ] Não foram utilizados GitHub Actions nem deploy automático.
