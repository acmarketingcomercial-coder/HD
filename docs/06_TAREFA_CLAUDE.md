# TASK 001 — AC Marketing Digital / Animated Business Stories

## Intenção
Converter este repositório em base operacional para produção serializada de Reels 2D narrativos da AC Marketing. O código fornecido é apenas *scaffold* mínimo e precisa ser auditado.

## Fase 1 — validar ambiente
- Confirmar versão Node LTS, dependências, compatibilidade Remotion/React e licença quando aplicável.
- Rodar instalação, `npm run check:inputs`, `npm run typecheck`, `npm run compositions`.
- Verificar importação da composição e renderizar `StoryPilot`; corrigir qualquer falha no seu próprio branch.
- Registrar no relatório versões, comandos executados, erros, status e caminhos de saída.
- Se não houver acesso a GPU, modelos de geração, som, fontes ou mídia, não inventar resultados.

## Fase 2 — elevar piloto técnico
- Criar um **teste audiovisual de 3–5 segundos** com avatar 2D adulto, microexpressão de curiosidade, cenário profissional multicamadas e movimento de câmera discreto.
- Dar continuidade visual: interação com tela/objeto que motiva a transição.
- Criar sprites/rig com partes isoladas de verdade, sem transformar imagem achatada em personagem articulado.
- Sound design curto original/licenciado se houver recursos; sem narração definitiva.
- Produzir frames (início, conflito, resolução), vídeo piloto e auditoria de qualidade. NÃO chamar de vídeo aprovado.

## Fase 3 — preparar base reutilizável
- Componentizar personagens, props, transições, cenários, tipografia, efeitos e controle de música/SFX.
- Estruturar pastas por `episodes/<id>` para roteiro, storyboard, assets e saída; não duplicar lógica.
- Criar contrato de dados de cena e documentação para novos episódios.
- Preservar estrutura simples, pouca dependência, versionamento e rastreabilidade.
- Não produzir filme completo até que roteiro Vfinal, storyboard, identidade e áudio tenham aprovação.

## Entregáveis
PR de implementação com build/typecheck, evidências e links/paths reais de outputs e log de bloqueios. Nunca afirmar que arquivos foram renderizados quando apenas escreveu código. Não tocar na main nem em backups sem autorização explícita de merge.

## Não negociáveis
- História humana, com conflito e descoberta, NÃO template de textos transitando.
- 4 regras de retenção documentadas.
- Valor aplicável para empresários com operações estruturadas.
- Audiovisual próprio, legalmente utilizável; não baixar vídeo/arte de terceiros sem licença.
- Qualquer mudança no conceito/copy é proposta para aprovação, não decisão técnica automática.
